# DriveParts: интернет-магазин автозапчастей

Учебный демо-проект: каталог запчастей с подбором по автомобилю, корзина, оформление заказа,
демо-оплата картой, личный кабинет и админка с дашбордом.

> Это демонстрационный проект. Товары, цены и заказы тестовые, деньги при «оплате» не списываются,
> данные карты нигде не сохраняются и не отправляются.

## Возможности

**Покупатель**
- Каталог с поиском (название, артикул, OEM-номер), фильтрами (автомобиль, категория, производитель, наличие) и сортировкой
- Подбор запчастей по автомобилю: у каждой запчасти указано, к каким авто она подходит
- Страница запчасти с галереей, характеристиками и похожими товарами
- Корзина, оформление заказа в три шага (контакты, доставка, оплата), расчёт стоимости доставки
- Демо-оплата картой с анимированной картой, проверкой номера (алгоритм Луна) и тестовыми сценариями
- Личный кабинет: профиль, смена пароля, адреса доставки, история заказов с дорожкой статусов

**Администратор**
- Дашборд: выручка, новые заказы, график за 14 дней, хиты продаж, товары на исходе
- Заказы: фильтр по статусам, смена статуса (при отмене запчасти возвращаются на склад)
- Запчасти: добавление, редактирование, удаление, загрузка нескольких фото, привязка к автомобилям
- Справочники: категории, производители, автомобили

## Технологии

Next.js (App Router, Server Actions), React, TypeScript, Tailwind CSS, PostgreSQL (Neon), Prisma,
Auth.js (вход по email и паролю), Vercel Blob (хранение фото).

## Запуск у себя

```bash
npm install
cp .env.example .env        # затем впишите свои значения
npx prisma migrate deploy   # создаст таблицы в базе
npx tsx prisma/seed.ts      # тестовые запчасти
npm run dev
```

Откройте http://localhost:3000. Чтобы сделать пользователя администратором:

```bash
npx tsx prisma/make-admin.ts your@email.com
```

## Тестовая оплата

- Успешная оплата: карта `4242 4242 4242 4242`, любой будущий срок и любой CVC
- Отказ банка: карта `4000 0000 0000 0002`

## Цветовая схема

Палитра переключается одной строкой в `src/lib/theme.ts`: `racing`, `blue`, `lime` или `orange`.

## Видео на заставке

Положите файл в `public/hero.mp4` и укажите `heroVideo: "/hero.mp4"` в `src/lib/site.ts`.
